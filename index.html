What Should I Do This Week?

  • Delegate one bounded engineering task with explicit verification and record what happened.
  • Run one product or distribution experiment that creates external evidence.
  • Improve one code-quality guardrail: type, test, lint, doc, or refactor.
  • Ingest one high-quality source and update the mention graph or candidate queue.

Promotion Rule

  • Promote when at least two high-quality sources or core mentors independently point to the same person/topic/tool.
  • Promote when one core mentor repeatedly references a person across multiple sources and the gap is important.
  • Keep thin evidence in the candidate queue. Do not guess.

Add A New Person

  • Use person-template.md.
  • Create source notes first when possible.
  • Update mention graph, candidates, source index, related pages, changelog, and this dashboard.
  • Use Browser to verify this page remains human-friendly.

Add A New Reference

  • Use source-note-template.md.
  • Extract durable lessons, not every detail.
  • Track mentioned people/tools/topics before promoting them.
  • Use Browser to verify search, links, and layout after major updates.
