# Planning Before Coding

## Purpose

A repeatable workflow for planning before coding in the AI Founder Knowledge Bank.

## Steps

1. Describe the outcome in user-visible terms.
2. Define constraints and non-goals.
3. Break work into demo-shaped slices.
4. Ask for options when the blast radius is unclear.
5. Choose verification before implementation.
6. Only then start coding or delegation.

## Checklist

- [ ] Outcome is concrete.
- [ ] Dependencies are known.
- [ ] Files likely touched are listed.
- [ ] Tests or Browser checks are defined.
- [ ] Rollback path exists.

## How This Applies To The Builder

Use this as an operating checklist before, during, or after delegating work to Codex/Claude. The goal is accepted output, not maximum agent activity.
