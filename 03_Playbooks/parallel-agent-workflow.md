# Parallel Agent Workflow

## Purpose

A repeatable workflow for parallel agent workflow in the AI Founder Knowledge Bank.

## Steps

1. Split work by disjoint files or independent research questions.
2. Give each agent a narrow scope and explicit output format.
3. Avoid delegating the immediate blocking task.
4. Keep a visible board of active, waiting, review, and done.
5. Integrate one result at a time.
6. Record collisions and improve future scoping.

## Checklist

- [ ] No overlapping write sets unless intentional.
- [ ] Each task has verification.
- [ ] Agent reports are short and source-backed.
- [ ] Human reviews all external effects.

## How This Applies To The Builder

Use this as an operating checklist before, during, or after delegating work to Codex/Claude. The goal is accepted output, not maximum agent activity.
