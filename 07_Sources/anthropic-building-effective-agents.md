# Building Effective Agents

**Source type:** article

**Author/person:** Anthropic

**URL:** [https://www.anthropic.com/research/building-effective-agents/](https://www.anthropic.com/research/building-effective-agents/)

**Date published:** 2024-12

**Date reviewed:** 2026-05-23

## Summary

Anthropic distinguishes workflows from agents and provides practical patterns for building agentic systems.

## Key Takeaways

- Prefer simple workflows when they solve the problem.
- Add autonomy only where it buys flexibility and the risk is bounded.
- Tool design and evaluation are central to useful agent systems.

## Claims Worth Importing

- Do not build agent swarms when a deterministic workflow is enough.
