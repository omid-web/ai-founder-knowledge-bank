# Not all AI-assisted programming is vibe coding

**Source type:** article

**Author/person:** Simon Willison

**URL:** [https://simonwillison.net/2025/Mar/19/vibe-coding/](https://simonwillison.net/2025/Mar/19/vibe-coding/)

**Date published:** 2025-03-19

**Date reviewed:** 2026-05-23

## Summary

Willison argues that professional AI-assisted programming still requires reading, testing, understanding, and owning the code.

## Key Takeaways

- Vibe coding is useful for experiments and personal tools, but production work requires accountability.
- Generated code should be explainable by the person shipping it.
- The boundary between prototype and production must be explicit.

## Claims Worth Importing

- Never ship AI-generated code you cannot explain and support.
