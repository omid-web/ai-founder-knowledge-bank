# Instead of hiring people, do things yourself

**Source type:** article

**Author/person:** Pieter Levels

**URL:** [https://levels.io/diy/](https://levels.io/diy/)

**Date published:** 2019

**Date reviewed:** 2026-05-23

## Summary

Levels argues for staying close to the work and using automation rather than premature hiring.

## Key Takeaways

- Doing work yourself teaches the system well enough to automate it.
- Agents should preserve closeness to the work, not hide it.

## Claims Worth Importing

- Automate after understanding the workflow by doing it manually.
