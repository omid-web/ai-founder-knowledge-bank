## Summary

Thariq discusses agent tool/action-space design lessons from Claude Code. The source is an X article and mirrors, so keep claims tied to the URL.

## Key Takeaways

- Design an agent's action space based on what the model can actually use well.
- Observe model behavior and iterate; agent tooling is empirical.
- Progressive discovery can beat exposing too many tools up front.

## Claims Worth Importing

- Agent tools should match model capability and feedback loops, not a theoretical taxonomy.
